# RapidRecruits
A sandbox to train the programming captains of tomorrow.
The focus is on learning by doing.
The course alternates between structured exploration of concepts and less structured building and debugging lessons.

## Prerequisites
WPILib VS Code and NI FRC Game Tools should be installed.
Git must be installed as well.
Basic Java knowledge is required, as well as some understanding of how WPILib operates.
This course attempts to assume that the learner does not know anything about WPILib, but may sometimes not be 100% clear.

## Getting started
To start, clone the repo and checkout level 1.0:
```bash
git clone https://github.com/RapidAcceleration-4593/RapidRecruits.git
cd RapidRecruits
git checkout level-1.0
```
