# Level 1.3 Building a Drivetrain

In this level, you will finish writing the code for the Drivetrain class which has been partially deconstructed.
It is strongly recommended that you **do not go back** and check your previous work.
That would defeat the purpose of the exercise, which is to struggle a little bit. 

## Important Files
[Drivetrain.java](./src/main/java/frc/robot/Drivetrain.java)

**Note: Classes related to simulation will be clearly labeled (either by name or by package).
Understanding simulation classes is not important for this course.**

## Instructions
### Part A. Writing the Code
1. Given the partially finished template in `Drivetrain.java`, finish writing the code so that the following conditions are met.

2. The robot must be able to drive around using the left stick as the forward control and the right stick as the turn control.

3. The robot must be able to accurately estimate its position on the field using `DifferentialDriveOdometry`.

4. The code must be free of any errors/bugs that can be found.

5. When finished, present to a senior programmer for inspection.
